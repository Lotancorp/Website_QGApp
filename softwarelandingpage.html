Getting started

Start with four simple steps.

You do not need programming experience. Set up your file locations, open a file, and choose the tool that matches your task.

1. Open Quartz Gallery

Start the app. If Windows asks for Administrator permission, choose Yes so the app can work with the files and folders it needs.

2. Set up Master Source

Click Master Source on the left. Add your RF Client, database, Excel, Resource.edf, or animation locations and click Save. Wait for indexing to finish.

3. Open a work folder and file

Choose Browse to add a folder to the left sidebar. Open it and double-click a text file to show it in the main editor.

4. Choose a tool and save

Use the matching tool for your task. Press Ctrl + S to save an edit. Named files in the main editor are also saved automatically every five minutes.

Keep a backup of important files before editing. New Untitled tabs and the server-provided Developer view are excluded from automatic saving. Minimized tool windows can be restored from the right panel.
